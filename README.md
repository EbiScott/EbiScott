<h3><b>Egbejule Eworitse (Ebi) - Security Engineer</b></h3>

ISC2 Certified in Cybersecurity, GDG Track Lead for Cybersecurity & Networking. I build offensive security tooling in Python and run hands-on exploitation work against real and lab targets.

**Shapeshifting LAN Defence** (Final Year Project): a detection-driven Moving Target Defence system for software-defined networks. Built on a Ryu OpenFlow 1.3 controller managing Open vSwitch in a Mininet-emulated LAN, it detects attacks in real time using four metrics; Shannon entropy of destination ports, SYN/ACK ratio, flow velocity, and connection frequency, and responds by dynamically reconfiguring the network: OpenFlow-based port hopping or timed source blocking, rather than waiting on a fixed mutation timer.

-- 🔨 Currently building **SafeCO** - a local-first, explainable monitor for unsafe industrial commands

-- 🕸️ **I_Sniff** (V1 shipped) - a Python/Scapy ARP MITM packet sniffer, with bidirectional ARP poisoning, DNS parsing, HTTP credential extraction, and a live terminal dashboard
